# remark.

一个以内容为主的 Markdown WebPPT 小框架。左侧写 Markdown，右侧实时预览；放映和翻页由 reveal.js 驱动。

![Markdown 编辑与图表实时预览](docs/images/editor-preview.png)

界面与幻灯片使用 [Nord](https://www.nordtheme.com/) Light / Dark 配色。首次打开跟随系统主题，可用顶部“深色 / 浅色”按钮切换；选择保存在本机浏览器。项目内置 JetBrains Mono Nerd Font、思源黑体 CN 和 LXGW 霞鹜文楷的 WOFF2 文件，字体授权文件位于 `public/fonts/`。

预览区的“字体”菜单支持默认、思源黑体、LXGW 霞鹜文楷和系统字体。默认保留原来的 Nerd Font + 思源黑体组合。选择会保存到浏览器，并同步到独立放映窗口和演讲者预览；图表与流程图沿用所选字体，代码和编辑器保持等宽。内置字体可离线使用；“系统字体”的实际外观取决于放映设备。

## 启动

需要 Node.js 22.12+。

```bash
npm install
npm run dev
```

打开终端显示的本地地址（通常是 `http://localhost:5173`）。部署静态页面时运行 `npm run build`，将 `dist/` 放到静态网站即可。

## 命令行

安装依赖后，在项目目录运行一次 `npm link`，即可在任意目录直接使用 `remark-ppt` 命令。

```bash
remark-ppt import pwn_binary_security.md
remark-ppt preview pwn_binary_security.md
remark-ppt present pwn_binary_security.md
```

本地 Vim 写稿时使用 `preview`：网页左侧只读显示 Markdown，右侧显示幻灯片；每次在 Vim 中 `:w` 保存，页面会自动读取新内容并保留当前页。`present` 也会同步文件，但启动后直接进入放映视图。浏览器限制自动进入系统全屏时，可再按 `F` 进入全屏。`import` 则是一次性载入可编辑网页，修改只保存在浏览器中；要保存文件请下载 Markdown。

三个命令都默认监听 `127.0.0.1:5175`，端口被占用时会提示错误。`--no-open` 只输出地址而不启动浏览器，`--port 5176` 可指定其他端口，`--port 0` 可自动选择空闲端口。`--json` 在标准输出中给出一行包含 `version`、`url`、`mode`、`file` 的 JSON，方便后续 NeoVim 插件通过后台任务调用。插件可解析启动行、打开 `url`，并在退出时向 CLI 进程发送 `SIGTERM`；诊断信息写在标准错误。按 `Ctrl+C` 停止服务。

本仓库的 [Pwn 纳新讲稿](pwn_binary_security.md) 已按 `---` 分页，可直接传给上述命令。

## 写幻灯片

放映页左下角的署名可在 Markdown 文件最开头声明：

```markdown
<!-- brand: 你的署名 -->
<!-- layout: cover -->
# 演讲标题
```

署名会显示在每页左下角，不进入第一页正文；未声明或内容为空时左下角留空。右下角始终显示 `remark.`。

- 每页写普通 Markdown；单独一行 `---` 开始下一页。
- 支持标题、列表、引用、链接、图片、表格和围栏代码块；在代码围栏后写语言名（如 `js`、`python`）即可语法高亮。
- 行内公式使用 KaTeX 渲染，推荐写 `\(P(x)=1\)`；也兼容已有讲稿中的 `$...$` 写法。代码块和行内代码中的公式标记保持原样。
- 用 `:red[文字]` 给局部文字上色；支持 `red`、`blue`、`green`、`yellow`、`purple` 五种基础色，深浅主题下都会调整为可读色。例如：`没有 Token 的 CS 学生应该:red[立即退学]`。方括号中仍可写 `**加粗**`。
- CLI 模式中的相对图片路径从 Markdown 所在目录解析；图片文件应放在该目录及其子目录中。
- 页面会自动保存在当前浏览器。可用“打开 Markdown”导入文件，用“下载”保存为 `slides.md`。
- 点击“开始放映”或在编辑框外按 `S`（或 `F`）打开独立放映窗口。将窗口移到投影屏后，在该窗口按 `F` 或点击“全屏”进入全屏；按 `Esc` 退出。原编辑窗口保留，内容和翻页状态同步到放映窗口。浏览器若拦截新窗口，需要允许当前站点的弹窗。
- 编辑框默认启用轻量 Vim 模式，可用编辑器右上角按钮关闭。普通模式支持 `h/j/k/l`、`w/b`、`0/$`、`gg/G` 移动，`i/a/I/A/o/O` 插入，`x`、`dd` 删除，`yy`、`p` 复制粘贴，`u` 和 `Ctrl+R` 撤销重做；`Esc` 返回普通模式。插入模式中的 `S`、`F` 等字母正常输入，放映快捷键仅在编辑框外生效。

### 局部字号

用 `::: size 字号` 和独立一行 `:::` 包住需要调整的段落或列表。支持 12–96 的整数字号；数字是 1280 × 720 幻灯片设计画布上的像素，预览与全屏会等比例缩放，默认正文字号为 34。块外恢复默认，块内仍支持 Markdown、公式和颜色标记。双栏中也可使用。标题仍按自身层级相对于所设字号放大；不支持嵌套字号块。

```markdown
# 项目进展

这段使用默认字号。

::: size 44
**本周重点：** :blue[完成核心功能]
:::

<!-- step -->
::: size 26
- 完成数据导入
- 完成实时预览

补充说明使用较小字号。
:::
```

需要逐步显示时，将 `<!-- step -->` 放在字号块外、该块之前。

### 放映快捷键

| 按键 | 功能 |
| --- | --- |
| `→`、`↓`、`Space`、`Page Down`、`N`、`J`、`L` | 下一页 |
| `←`、`↑`、`Page Up`、`H`、`K`、`Shift+Space` | 上一页 |
| `Home` / `End` | 首页 / 末页 |
| `O` | 幻灯片总览 |
| `B` 或 `.` | 黑屏暂停，再按一次恢复 |
| `G` | 跳转到指定页 |
| `?` 或 `F1` | 快捷键帮助 |
| `S` | 预览时打开独立放映窗口 |
| `P` | 打开演讲者视图，显示当前页、下一页、备注和计时器 |
| `F` | 预览时打开独立放映窗口；放映窗口内进入浏览器全屏 |
| `Esc` | 退出放映；总览或帮助打开时先关闭对应界面 |

本项目保留 `Esc` 退出放映的交互；reveal.js 原版的 `Esc` 也可切换总览。`S` 在本项目中用作放映入口，`P` 用作演讲者视图入口；自动翻页尚未启用，因此 `A` 暂无对应功能。

在每页末尾添加 `<!-- notes -->`，后面到下一页分隔线之间的 Markdown 就是演讲者备注。备注不在幻灯片上显示。编辑框外按 `P` 打开演讲者窗口，投影时把主放映窗口放在投影屏上，演讲者窗口留在自己的屏幕上。若浏览器拦截弹窗，需要允许当前站点打开弹窗。

```markdown
# 展示给观众的标题

这里是观众看到的内容。

<!-- notes -->

- 开场先问大家一个问题。
- 这一页控制在一分钟内。

---

# 下一页
```

打开页面时会显示一份示例。修改后会保存到浏览器本地；换浏览器或清理站点数据时，请先下载 Markdown 备份。

## 逐步显示

在模块前写 `<!-- step -->`。标记前的内容立即显示，之后每一组内容按一次下一步出现。`→`、`Space`、`J` 或右侧翻页按钮会先展示本页下一组，全部展示后才翻到下一页；上一操作可逐步收回。双栏页可在各栏中使用相同标记，按左栏、右栏的顺序展示。

```markdown
# 我的观点

这句话一开始就显示。

<!-- step -->

## 第一个模块
- 两条要点一起出现
- 同一个模块内无需重复标记

<!-- step -->

![第二步出现的图片](images/example.png)
```

## 图表与流程图

使用 `mermaid` 围栏写流程图、时序图等。图形在浏览器本地生成，语法错误会显示在对应幻灯片中。

````markdown
```mermaid
flowchart LR
  A[收集需求] --> B[实现]
  B --> C[验证]
```
````

使用 `chart` 围栏写数据图。目前支持 `bar`（柱状）、`line`（折线）、`doughnut`（环形），标签和数值各写一行，最多 12 项。

````markdown
```chart
type: bar
title: 活动参与人数
labels: 一班, 二班, 三班
values: 18, 24, 21
```
````

## 文字版式

在一页开头放一行版式注释；不写时使用普通版式。版式只改变文字层级和留白，沿用当前 Nord 主题。

- `<!-- layout: cover -->`：封面，大标题和副标题。
- `<!-- layout: section -->`：章节过渡，标题与导语。
- `<!-- layout: statement -->`：一句核心判断。
- `<!-- layout: split -->`：标题下双栏，用 `<!-- column -->` 分开左右内容。

````markdown
<!-- layout: split -->
# 项目回顾

### 遇到的问题
- 进度不透明

<!-- column -->

### 改进方案
- 每周更新里程碑
````

建议把结论写成标题，让每页只承担一个观点；关键数字、引语、图表各占一页时更容易被看清。固定画布仍有内容上限，较长的列表和大型图形需要分成多页。

## 技术结构

- `src/slides.js`：按 `---` 分页，并避开代码块中的分隔线。
- `src/main.js`：编辑、保存、导入导出与放映交互。
- `src/visuals.js`：解析版式与简短图表配置。
- `src/style.css`：编辑界面与内容优先的幻灯片主题。

Markdown 经 `marked` 渲染，再由 `DOMPurify` 清理 HTML。静态页面不需要服务端或账户；CLI 会启动仅监听本机的临时预览服务。
